claude-video (/watch).
SkillCriar e editar vídeo

claude-video (/watch)

bradautomates/claude-video

Dá ao Claude a capacidade de assistir um vídeo: baixa, extrai quadros com horário e transcreve, e entrega tudo para ele analisar.

Para que serve
  • Mandar o link de um vídeo do YouTube e o Claude resumir, citar trechos e mostrar o que aparece na tela
  • Achar o nome de um repositório ou site que aparece na tela do vídeo
  • Revisar o seu próprio vídeo antes de publicar

Funciona sem chave de API, usando a legenda do vídeo e quadros da tela. Precisa de Python 3.10 ou mais novo, ffmpeg, yt-dlp e, para o YouTube, o Deno. Para ler texto pequeno na tela, peça um trecho curto em resolução maior.

Como começar

No Claude Code: /plugin marketplace add bradautomates/claude-video e /plugin install watch@claude-video. Depois, mande o link do vídeo e a pergunta.

Impeccable

pbakaus/impeccable

Vocabulário de design para o agente: comandos para revisar (critique, audit), dar acabamento (polish, bolder, quieter) e um detector com 62 regras que pega a cara de IA antes de publicar.

Para que serve
  • Achar a cara de IA numa página pronta: Inter em tudo, degradê roxo, card dentro de card, contraste ruim
  • Pedir ao agente uma crítica de UX ou uma passada final de acabamento com um comando só
  • Rodar "npx impeccable detect" numa pasta ou num endereço, sem instalar nada

Ao instalar, cria um hook que verifica toda edição de interface e baixa um programa próprio. Tem telemetria anônima, que desliga com "npx impeccable telemetry off". Mesmo espaço da Taste Skill, da Hallmark e do Unslop.

Como começar

Teste sem instalar: npx impeccable detect . na pasta do seu site. Para instalar: npx impeccable install.

Screenshot to Code

abi/screenshot-to-code

Alternativa av0 e Lovable (a partir de um print)

Transforma um print, ou uma gravação de tela, em código pronto: HTML com Tailwind, React, Vue ou Bootstrap.

Para que serve
  • Print de uma tela vira protótipo editável para propor melhoria
  • Gravação do fluxo de outro app vira protótipo clicável para comparar

Precisa de chave de API paga (Anthropic, OpenAI ou Gemini), não usa a assinatura do Claude. O Claude Code já transforma print em HTML, inclusive direto no Doop. A versão de nuvem não deve receber tela com dado sensível.

Como começar

Teste em screenshottocode.com com um print sem dado sensível. Para rodar local, precisa de chave de API.

Os tipos.

O que cada etiqueta quer dizer
App

Programa com tela própria. Roda no computador, no navegador ou num servidor seu.

Skill

Instruções que ensinam o Claude Code (ou outro agente) a fazer um trabalho. Instala com um comando e vira um /comando.

Terminal

Ferramenta sem tela, usada por comando. Dá para pedir ao Claude Code rodar por você.

Biblioteca

Código para usar dentro de um projeto de programação.

Modelo

Modelo de IA que roda no seu computador, sem serviço externo.

MCP

Ponte que deixa o Claude controlar outro programa.

Componentes

Peças de interface prontas para copiar num site ou app.

Plugin

Extensão que muda o próprio Claude Code.

Dados

Base de informação para consultar.

Antes de instalar.

  • Dado sensível, seu ou de cliente, não vai para versão de nuvem de terceiro. Várias destas ferramentas têm versão cloud; use a que roda na sua máquina.
  • GPL e AGPL podem ser usadas por conta própria. Colocar dentro de um produto vendido exige cuidado com a licença.
  • Projeto de terceiro que você ainda está avaliando roda melhor em Docker, isolado do resto da máquina.
  • Skill é texto: leia o arquivo antes de instalar e veja o que ela manda o agente fazer.
  • Confira de novo a licença e a atividade do repositório no dia da instalação.
