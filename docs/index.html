Os tipos.

O que cada etiqueta quer dizer
App

Programa com tela própria. Roda no computador, no navegador ou num servidor seu.

Skill

Instruções que ensinam o Claude Code (ou outro agente) a fazer um trabalho. Instala com um comando e vira um /comando.

Terminal

Ferramenta sem tela, usada por comando. Dá para pedir ao Claude Code rodar por você.

Biblioteca

Código para usar dentro de um projeto de programação.

Modelo

Modelo de IA que roda no seu computador, sem serviço externo.

MCP

Ponte que deixa o Claude controlar outro programa.

Componentes

Peças de interface prontas para copiar num site ou app.

Plugin

Extensão que muda o próprio Claude Code.

Dados

Base de informação para consultar.

Antes de instalar.

  • Dado sensível, seu ou de cliente, não vai para versão de nuvem de terceiro. Várias destas ferramentas têm versão cloud; use a que roda na sua máquina.
  • GPL e AGPL podem ser usadas por conta própria. Colocar dentro de um produto vendido exige cuidado com a licença.
  • Projeto de terceiro que você ainda está avaliando roda melhor em Docker, isolado do resto da máquina.
  • Skill é texto: leia o arquivo antes de instalar e veja o que ela manda o agente fazer.
  • Confira de novo a licença e a atividade do repositório no dia da instalação.
